# AT JumpServer Terminal 0.1.8 Release Notes

Version 0.1.8 introduces native VS Code internationalization (i18n / l10n) across all JumpServer asset trees, SFTP session management, terminal interactions, and configuration panels, delivering complete bilingual (English / Simplified Chinese) support.

## Highlights & New Features

### 1. VS Code Native Internationalization & Localization (l10n)
- **Standard `vscode.l10n` Infrastructure**: Implemented lightweight `t()` localization helper leveraging VS Code's official localization runtime with parameter interpolation and fallback resilience.
- **Bilingual Manifest Localization**: Migrated extension commands, tree view titles, configuration options, and context menus to `%atJumpServer...%` localization tokens backed by `package.nls.json` and `package.nls.zh-cn.json`.
- **Runtime Localization Bundles**: Added runtime localization bundle `l10n/bundle.l10n.zh-cn.json` supporting seamless locale switching.

### 2. JumpServer Asset Trees & Terminal Interactions
- **Asset Tree & Context Actions**: Localized asset hover tooltips, copy host IP actions, protocol indicators, and unsupported protocol warning notifications across SSH, MySQL, and Redis assets.
- **Terminal Session Feedback**: Localized terminal lifecycle notifications, connection indicators, and reconnect toasts.

### 3. SFTP Management & Safety Guards
- **SFTP Workflow Localization**: Localized file upload, download, preview, edit, rename, delete, and directory creation prompts and status notifications.
- **File Guard & Buffer Dialogs**: Localized confirmation modals for large file streaming downloads, binary file editing guard alerts, and dirty buffer discard warnings.

### 4. Webview & Configuration Panels
- **JumpServer Config Form (`JumpServerConfigPanel`)**: Localized all configuration inputs, authentication mode options, endpoint URLs, token descriptions, and validation errors.
- **Webview Localization Contract**: Standardized localization string injection across all webview panels and terminal interfaces.

### 5. Automated Testing
- **i18n Test Suites**: Added `test/i18n/nls.test.ts` and `test/i18n/t.test.ts` validating NLS key parity and runtime substitution across all 424 unit and integration tests.
