# AT JumpServer Terminal 0.1.9 Release Notes

Version 0.1.9 adds multiple JumpServer bastions in one asset tree, aligns REST login / organization / pagination with JumpServer, and reuses the per-bastion Bearer token and KoKo web session so later connects skip a full login. SSH connect binds the Files view without opening SFTP until the first Refresh.

## Highlights & New Features

### 1. Multiple JumpServer Bastions
- **Independent lifecycle**: Add, edit, remove, refresh, and validate each bastion on its own. The asset tree groups hosts under a bastion root.
- **Display name and organization**: The config form stores an optional display name. Validate and Refresh require an organization when the account can see more than one; an empty org ID no longer mixes inventories.
- **MCP bastion scope**: Asset list rows include `bastionId`. Agent tools create the client for that bastion.

### 2. JumpServer REST Alignment
- **Form-urlencoded login fallback**: When JSON `/authentication/auth/` does not return a token, retry as `application/x-www-form-urlencoded`.
- **401 vs 403**: Only HTTP 401 refreshes the Bearer token. HTTP 403 is forbidden, not expired auth.
- **Pagination and throttle**: Follow `next` and count/offset on asset and org lists; wait on HTTP 429 using JumpServer's hint.
- **Error bodies and Date**: Surface API `detail` and send an RFC 1123 `Date` header on REST calls.

### 3. Faster Connects and Lazy SFTP
- **Per-bastion client pool**: One `JumpServerClient` per bastion identity (URL, username, password, TLS). Org changes use `setOrgId` instead of a new login.
- **Serialized login**: Overlapping connects run one REST Bearer login and one KoKo form login. A KoKo 302 that is not a login page counts as already authenticated.
- **Prefetch and caches**: Selecting an asset prefetches detail. The KoKo smart-endpoint host/port is reused; each connect still mints a new connection-token.
- **WebSocket before HTML warmup**: If a `sessionid` cookie exists, open the terminal or SFTP socket first and warm up only when the handshake fails.
- **No SFTP on SSH connect**: Files shows a pending placeholder. Toolbar Refresh (or the first list) opens the SFTP session.

### 4. Localization and Diagnostics
- **Chinese locale aliases**: `zh-hans` and `zh` bundles match `zh-cn` so forks such as Antigravity keep Chinese UI.
- **Connect timing logs**: The AT JumpServer Terminal channel logs client create/reuse, Bearer login/reused, warmup, and connect duration without token URLs.
