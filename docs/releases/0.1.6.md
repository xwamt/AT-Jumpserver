# AT JumpServer Terminal 0.1.6 Release Notes

Version 0.1.6 delivers major hardening, performance upgrades, and security improvements across JumpServer asset management, terminal streaming, and MCP Agent integration.

## Highlights & New Features

### 1. Transport Hardening & Strict TLS Verification
- **Dual-Channel TLS Enforcement**: `verifyTls` setting now applies to both WebSocket and REST transport layers via `node:https`.
- **Cross-Origin Redirect Refusal**: Refuses cross-origin redirects and restricts Cookie Jar scoping to prevent token/session leakage.
- **Strict Deadlines on HTTP/WebSocket**: Enforces per-request deadlines with abort signal handlers to prevent wedged socket hangs.

### 2. Stream-Bounded SFTP & Bounded Payload Protection
- **Bounded Stream SFTP Read**: `jumpserver_sftp_read_file` reads files via bounded streaming chunks up to `maxBytes` (default 64KB, hard cap 256KB) with backpressure support, eliminating the risk of downloading massive files into memory.
- **Directory List Paging**: `jumpserver_sftp_list_directory` enforces a 500-entry default limit with `truncated: true` and `total` counters.
- **Clamped Command & SQL Outputs**: Terminal and MySQL output buffers clamp default captures to 64KB (hard max 256KB).

### 3. Asset Search & Pagination
- **Server-Side Paging**: `jumpserver_list_assets` adds `search`, `limit`, and `offset` parameters for seamless navigation through large enterprise asset directories.
- **Eliminated Redundant Node Fetching**: Fixed double-pulling of asset node trees during view refreshes.

### 4. Terminal & Webview Resilience
- **KoKo Socket Dead-State Detection**: Detects dead KoKo PTY sockets and bounds message queues to prevent memory bloat.
- **Webview Message Boundary Validation**: Enforces strict positive integer validation on PTY rows/columns crossing the webview boundary.
- **Batch Base64 Terminal Output**: Collapses high-frequency PTY WebSocket frames into batched Base64 frames (8ms / 64KB).
- **Idle Disconnect Support**: Implements `jumpserverManager.idleDisconnectMinutes` for automatic terminal session cleanup.

### 5. MCP Bridge Security & Confirmation Modal
- **Pre-Buffer Authentication Gate**: Rejects unauthenticated requests and invalid tokens at the header level before buffering request bodies.
- **Constant-Time Token Comparison**: Employs `timingSafeEqualToken` to eliminate timing side-channel risks.
- **State-Changing SQL Confirmation**: Non-read-only SQL statements (`UPDATE`, `DELETE`, `DROP`, `SET`, etc.) trigger IDE confirmation modals before execution.
