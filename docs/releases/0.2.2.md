# AT JumpServer Terminal 0.2.2 Release Notes

Version **0.2.2** builds on the CSRF and terminal reconnect baseline from `v0.2.1` to deliver **JumpServer 5.0 protocol & account mode alignment**, **terminal/SFTP stability fixes**, **UI & workflow refinements**, **tree-indexing & streaming SFTP performance improvements**, and **progressive module decomposition**.

## Highlights & Changes

### 1. JumpServer 5.0 Protocol & Account Alignment
- **Dynamic `connect-methods` negotiation**: Queries and caches `/api/v1/terminal/components/connect-methods/` (30s TTL) to prefer `web_cli` / `db_client` / `web_sftp`, adds **MariaDB** protocol support, and surfaces clear errors for unsupported native/applet/virtual-app methods.
- **KoKo 5.0 capability detection & cookie-less handshake**: Probes `client/versions` (with 404 fallback and per-bastion cache invalidation) and adds the opt-in `jumpserverManager.kokoBearerHandshake` setting to send `Authorization: Bearer` directly on KoKo 5.0 WebSocket handshakes with automatic ticket fallback on HTTP 401.
- **Alias accounts & multi-account switching**: Supports managed and alias account refs (`@USER`, interactive `@INPUT`, `@ANON`, `@ALL`, `@SPEC`), remembers the last selected account per asset, and exposes a concise right-click **Connect Asset** (**连接资产**) action to switch accounts on multi-account assets.
- **Safe terminal-to-SFTP token reuse**: Reuses eligible terminal connection tokens when lazily opening SFTP and automatically falls back to a fresh `web_sftp` session if token reuse fails handshake.

### 2. Stability & Defect Fixes
- **Initial PTY sizing & reconnect preservation**: Records `resize(rows, cols)` dimensions even before WebSocket connection opens and preserves viewport dimensions across `reconnect()`.
- **Structured terminal status & live configuration reload**: Emits structured `connecting` / `connected` / `disconnected` state events (correctly recognizing both English and Chinese disconnect messages), displays the active host + protocol label in the terminal status bar, syncs editor tab bar `$(sync)` reconnect state, and hot-reloads font size, font family, scrollback, semantic highlight, and idle disconnect settings on open panels.
- **SFTP heartbeat & auto-reconnect**: Adds 20s/15s WebSocket `ping`/`pong` heartbeats (`unref()` timers) and automatically disposes and rebuilds broken SFTP sessions on the next user action.
- **Cache invalidation on bastion changes**: Drops `JumpServerClientPool` entries, invalidates KoKo capability caches when bastions are saved/deleted or `kokoBearerHandshake` changes, fixes SFTP edit status-bar timer races and sync file `stat`, cleans up completed MCP `terminalQueues` entries, and restores `$(refresh)` / `$(edit)` / `$(trash)` inline bastion icons so hover buttons never obscure bastion domains.

### 3. UI & Workflow Enhancements
- **Command Palette cleanup & global QuickPick connect**: Hides tree-context-only commands from the Command Palette while enabling `JumpServer: Connect` globally via searchable asset QuickPick (by name, IP, bastion, or group).
- **Asset tree icons & concise context menu**: Adds `ThemeIcon` differentiation across bastions, groups, SSH, MySQL/MariaDB, Redis, and unsupported assets; shortens the asset right-click connect label to **Connect Asset** / **连接资产**.
- **SFTP browser UX**: Clicking the pending SFTP placeholder triggers Refresh & lazy connect, clicking an active file opens Preview, and new **Go to Path**, **New File**, and **Open in Terminal** (`cd` active SSH terminal) actions are available.
- **Config panel improvements**: Adds field placeholders/hints, an inline **Test Connection** button (validates credentials and probes accessible orgs without saving or closing the panel), and disabled busy states during requests.

### 4. Performance & Architecture
- **Cached bastion tree indexing**: `JumpServerTreeProvider` builds a per-refresh `BastionTreeIndex` so expanding sub-groups avoids repeatedly filtering all cached assets.
- **Streaming SFTP chunked upload**: `JumpServerSftpSession.uploadFromFile` streams files via `open()` with a single reusable 4 MiB buffer instead of reading entire files into heap memory at once.
- **Maintainability & hygiene**: Hardens `nls.test.ts` against unused keys and XSS test payloads in production l10n bundles, deduplicates `package.json` policy-asset copy build steps, and splits `JumpServerClient.ts` (`cookieJar.ts`, `assetNormalizer.ts`, `tokenPayload.ts`, `kokoEndpoints.ts` with re-exports) and `extension.ts` (`src/commands/{bastionCommands,assetCommands,sftpCommands,mcpCommands}.ts`) while preserving strict bundle isolation between `dist/extension.js`, `dist/mcpRuntime.js`, and `dist/policy-runtime.js`.
